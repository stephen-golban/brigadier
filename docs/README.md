# Documentation

This is the index of brigadier's documentation. The top-level
[README](../README.md) is the short introduction: install the binary, run
`brigadier init` once, and make a first run. These documents cover each subject
in depth.

| Document | What it covers |
| --- | --- |
| [CLI.md](CLI.md) | the complete command reference: setup, every command, option, and exit code |
| [AGENT-SETUP.md](AGENT-SETUP.md) | a step-by-step guide for an AI agent setting brigadier up for a user |
| [PLAN-FORMAT.md](PLAN-FORMAT.md) | the plan document: every field, validation rule, and error code |
| [REVIEW-GATE.md](REVIEW-GATE.md) | the cross-vendor review gate in depth |
| [HOSTS.md](HOSTS.md) | what `brigadier install` writes per host and each host's limits |
| [METHODOLOGY.md](METHODOLOGY.md) | the routing policy, published so it can be audited for vendor bias |
| [RELEASING.md](RELEASING.md) | release artifacts and the release procedure |

Start with [../README.md](../README.md), then run `brigadier init`. Read
[CLI.md](CLI.md) for exact command behavior, [PLAN-FORMAT.md](PLAN-FORMAT.md)
before writing a plan, and [HOSTS.md](HOSTS.md) when choosing or troubleshooting
an integration.
